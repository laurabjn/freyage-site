À offrir

Carte cadeau

Offrez un moment de beauté, pour un anniversaire, Noël ou un mariage. Choisissez le montant, réglez en ligne, et je vous envoie votre code par e-mail.

Paiement sécurisé par Stripe, où vous indiquerez votre nom et votre e-mail. Pour indiquer le prénom de la personne qui reçoit la carte, répondez simplement à l'e-mail contenant votre code. En payant, vous acceptez les conditions générales de vente. Données personnelles

Comment ça marche ?

  1. Vous choisissez le montant de la carte, à partir de 20 €.
  2. Vous réglez en ligne par carte bancaire, sur la page sécurisée de Stripe.
  3. Vous recevez le code par e-mail, à transmettre à la personne de votre choix.

Pour la personne qui la reçoit

Elle indique son code dans sa demande de rendez-vous, en choisissant « Avec une carte cadeau ». La carte est valable 6 mois à compter de l'achat. Si elle ne couvre pas toute la prestation, le solde se règle sur place, par carte bancaire ou en espèces. Si elle coûte moins, le reste est gardé pour un prochain rendez-vous, pendant la durée de validité. Code perdu ? Contactez-moi : je garde une trace de chaque carte et je le retrouve.

Bon à savoir

  • Montant personnalisable
  • Règlement en ligne par carte bancaire
  • Code envoyé par e-mail après le paiement
  • Code à indiquer lors de votre demande de rendez-vous
  • Valable 6 mois à compter de l'achat
